# X86 Architecture

## What is X86?

X86 is a family of **Instruction Set Architectures (ISA)** originally developed by Intel for the 8086 processor (1978).
The name comes from the pattern: 8086 → 80186 → 80286 → 80386 → 80486, all ending in **86**.

Modern x86 refers to two variants:
- **x86 (IA-32)** — 32-bit
- **x86-64 (AMD64)** — 64-bit (AMD designed it, Intel adopted it)

> **Mnemonic:** "**E**ight-six = **E**veryone's **S**ix-layer **I**nstruction **X**engine"
> X86 is the **lingua franca** of desktop/server CPUs.

---

## Operating Modes

| Mode         | Width | When Used                        |
|--------------|-------|----------------------------------|
| Real Mode    | 16-bit | Boot time, legacy BIOS           |
| Protected Mode | 32-bit | Modern 32-bit OS                |
| Long Mode    | 64-bit | Modern 64-bit OS (x86-64)        |

> **Mnemonic: "RPL" — Real → Protected → Long**
> Think of it as **R**ookie → **P**rofessional → **L**egend — each mode gets more powerful.

## Registers

Registers are the CPU's "scratchpad" — tiny, ultra-fast storage inside the chip.

### General Purpose Registers (x86-64)

| 64-bit | 32-bit | 16-bit | 8-bit | Purpose (convention)       |
|--------|--------|--------|-------|----------------------------|
| RAX    | EAX    | AX     | AL/AH | **A**ccumulator (math ops, return values) |
| RBX    | EBX    | BX     | BL/BH | **B**ase (base pointer, preserved) |
| RCX    | ECX    | CX     | CL/CH | **C**ounter (loops, shifts) |
| RDX    | EDX    | DX     | DL/DH | **D**ata (I/O, multiply overflow) |
| RSI    | ESI    | SI     | SIL   | **S**ource **I**ndex (string ops src) |
| RDI    | EDI    | DI     | DIL   | **D**estination **I**ndex (string ops dst) |
| RSP    | ESP    | SP     | SPL   | **S**tack **P**ointer (top of stack) |
| RBP    | EBP    | BP     | BPL   | **B**ase **P**ointer (stack frame base) |
| R8–R15 | R8D–R15D | R8W–R15W | R8B–R15B | Extra registers (x86-64 only) |

> **Mnemonic: "All Browsers Can Display Some Digital Pages Brilliantly"**
> **A**AX → **B**BX → **C**CX → **D**DX → **S**SI → **D**DI → **P**SP → **B**BP

### Special Registers

| Register | Name              | Purpose                                |
|----------|-------------------|----------------------------------------|
| RIP      | Instruction Pointer | Points to the **next** instruction to execute |
| RFLAGS   | Flags Register    | Holds status bits (zero, carry, overflow…) |

> **Mnemonic:** RIP = "**R**ead **I**t **P**ointed" — the CPU always reads from where RIP points.

### Key RFLAGS Bits

| Flag | Bit | Meaning                        |
|------|-----|--------------------------------|
| CF   | 0   | **C**arry — unsigned overflow  |
| ZF   | 6   | **Z**ero — result was zero     |
| SF   | 7   | **S**ign — result was negative |
| OF   | 11  | **O**verflow — signed overflow |

> **Mnemonic: "Carry Zero Sign Overflow" → "**C**ats **Z**ap **S**leepy **O**tters"**

## Memory & Addressing

X86 uses a **flat memory model** in protected/long mode — all memory is one big array of bytes, addressed linearly.

### Addressing Modes

```
[base + index * scale + displacement]
```

- **base** — a register (e.g. `RBX`)
- **index** — a register multiplied by scale
- **scale** — 1, 2, 4, or 8
- **displacement** — a constant offset

Examples:
```asm
mov rax, [rbx]              ; base only
mov rax, [rbx + 8]          ; base + displacement
mov rax, [rbx + rcx*4]      ; base + index*scale
mov rax, [rbx + rcx*4 + 8]  ; full form
```

> **Mnemonic: "BISD" — Base + Index × Scale + Displacement**
> "**B**ig **I**guanas **S**teal **D**oughnuts" — always in that order.

## The Stack

The stack is a **Last-In First-Out (LIFO)** region of memory.
- **RSP** always points to the **top** (lowest address — it grows **downward**).
- `PUSH` decrements RSP then writes. `POP` reads then increments RSP.

```asm
push rax    ; RSP -= 8; [RSP] = rax
pop  rbx    ; rbx = [RSP]; RSP += 8
```

> **Mnemonic:** The stack is like a **stack of plates** — you always add/remove from the top, and it grows toward the floor (lower addresses).

### Stack Frame (Function Call Layout)

```
High address
┌─────────────────┐
│   caller's data │
├─────────────────┤  ← RBP (base of current frame)
│   saved RBP     │
│   local vars    │
│   ...           │
├─────────────────┤  ← RSP (top of stack)
Low address
```

## Common Instructions

### Data Movement

| Instruction | Example            | Meaning                        |
|-------------|--------------------|--------------------------------|
| `MOV`       | `mov rax, 1`       | Copy value into register       |
| `LEA`       | `lea rax, [rbx+4]` | Load **address** (not value)   |
| `PUSH/POP`  | `push rax`         | Stack operations               |
| `XCHG`      | `xchg rax, rbx`    | Swap two values                |

> **Mnemonic:** MOV = "**M**ove **O**ver **V**alue", LEA = "**L**oad **E**ffective **A**ddress"

### Arithmetic

| Instruction | Example         | Meaning              |
|-------------|-----------------|----------------------|
| `ADD`       | `add rax, rbx`  | rax = rax + rbx      |
| `SUB`       | `sub rax, 1`    | rax = rax - 1        |
| `IMUL`      | `imul rax, rbx` | rax = rax * rbx (signed) |
| `IDIV`      | `idiv rcx`      | rdx:rax / rcx        |
| `INC/DEC`   | `inc rax`       | rax += 1 / rax -= 1  |

### Bitwise / Logic

| Instruction | Meaning              |
|-------------|----------------------|
| `AND`       | Bitwise AND          |
| `OR`        | Bitwise OR           |
| `XOR`       | Bitwise XOR (use `xor rax, rax` to zero a register) |
| `NOT`       | Bitwise NOT          |
| `SHL/SHR`   | Shift left/right     |

> **Mnemonic:** `xor rax, rax` = fastest way to **zero** a register (anything XOR itself = 0).

### Control Flow

| Instruction | Meaning                                 |
|-------------|-----------------------------------------|
| `CMP`       | Subtract and set flags (discard result) |
| `TEST`      | AND and set flags (discard result)      |
| `JMP`       | Unconditional jump                      |
| `JE/JZ`     | Jump if Equal / Zero flag set           |
| `JNE/JNZ`   | Jump if Not Equal                       |
| `JG/JL`     | Jump if Greater / Less (signed)         |
| `CALL`      | Push RIP, jump to function              |
| `RET`       | Pop RIP, return from function           |

> **Mnemonic:** CALL/RET = "**C**ome **A**nd **L**isten **L**ater / **R**eturn **E**very **T**ime"

### System Calls (Linux x86-64)

Arguments are passed in registers in this order:

```
syscall number → RAX
arg 1          → RDI
arg 2          → RSI
arg 3          → RDX
arg 4          → R10
arg 5          → R8
arg 6          → R9
```

> **Mnemonic: "**A**lways **D**rink **S**oda **D**uring **R**oad **T**rips"**
> **A**AX, **D**DI, **S**SI, **D**DX, **R**10, **R**8, **R**9

Example — write "hello" to stdout:
```asm
mov rax, 1       ; syscall: write
mov rdi, 1       ; fd: stdout
mov rsi, msg     ; buffer
mov rdx, 5       ; length
syscall
```

## Calling Conventions (System V AMD64 — Linux/macOS)

### Integer/Pointer Arguments (in order)

```
RDI, RSI, RDX, RCX, R8, R9 → then stack
```

> **Mnemonic: "**D**ogs **S**it **D**own **C**orrectly **8** out of **9** times"**

### Return Value
- Integers/pointers → `RAX` (and `RDX` for 128-bit)

### Caller-saved (may be clobbered by callee)
`RAX, RCX, RDX, RSI, RDI, R8, R9, R10, R11`

### Callee-saved (must be preserved by callee)
`RBX, RBP, R12, R13, R14, R15`

> **Mnemonic:** Callee-saved = "**B**etter **B**ackup **R**eliably" → RBX, RBP, R12–R15

## Quick Reference Card

```
Registers:  RAX RBX RCX RDX RSI RDI RSP RBP R8–R15 RIP RFLAGS
Stack:      grows DOWN | RSP = top | RBP = frame base
Addressing: [base + index*scale + displacement]
Syscall:    RAX=number, args in RDI RSI RDX R10 R8 R9
Call conv:  args: RDI RSI RDX RCX R8 R9 | ret: RAX
```
